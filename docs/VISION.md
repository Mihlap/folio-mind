# Vision — Folio Mind

## Одно предложение

**Folio Mind** — платформа полного цикла работы с PDF: просмотр, версии, права, хранение в S3, фоновая обработка и **ИИ-помощник** (аудит, правки с подтверждением, чат, RAG), без разработки собственного PDF-движка.

## Позиционирование

- **Acrobat-class + AI-native workflow** — не клон интерфейса Adobe Acrobat.
- Юридически и по бренду — **отдельный продукт**; технически — надёжная работа с PDF, конвертация и подпись на проверенных библиотеках.
- ИИ **предлагает и черновит**; подпись, отправка и публикация — **только после явного действия** пользователя с записью в журнал аудита.

## Сценарий v1 (фокус разработки)

1. Загрузка договора PDF (в т.ч. 10+ МБ, presigned upload в S3).
2. Просмотр в браузере (PDF.js, превью страниц в фоне).
3. ИИ-проверка рисков (GigaChat или YandexGPT — по конфигу заказчика).
4. Отчёт + чат по документу.

## Критерии «готово» для v1

| Критерий | Описание |
|----------|----------|
| Загрузка | Большие PDF через presigned URL; метаданные и версии в Postgres |
| Просмотр | Viewer без блокировки UI; превью страниц асинхронно (worker) |
| ИИ | Саммари и чат через очередь, не блокируя API; кэш по версии документа |
| Безопасность | JWT, tenant isolation, audit log, rate limits |
| Наблюдаемость | request_id, базовый OpenTelemetry (опционально в dev) |
| Юридика | Дисклеймеры ИИ; черновики Privacy/DPA в `docs/legal/` |

## Вне v1 (но в дорожной карте)

- Буклеты и согласование с заказчиком (фаза **2b**).
- Конвертация Office ↔ PDF, формы, PAdES (фаза **3**).
- PWA и Android APK (фаза **4**).

## Платформы

| Платформа | Подход |
|-----------|--------|
| Web | Один React-код: телефон → ultra-wide |
| Android | Capacitor (APK/AAB), тот же фронт |
| PWA | Дополнительный канал без магазина |
| Desktop | Только браузер, без .exe/.dmg-оболочки |

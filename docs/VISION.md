# Vision

Folio Mind — платформа полного цикла работы с PDF: просмотр, версии, ИИ-проверка, буклеты и согласование с заказчиком без «скачай и перекинь».

**ICP и сценарий v1:** [ICP.md](./ICP.md) (договор + ИИ-проверка рисков).

## v1 готово, когда

1. Пользователь загружает договор PDF (presigned S3, 10+ МБ).
2. Просматривает документ (превью + PDF.js без подвисаний).
3. Запускает ИИ-проверку рисков (очередь, GigaChat или YandexGPT).
4. Получает отчёт и может уточнить в чате.
5. Действия фиксируются в журнале аудита.

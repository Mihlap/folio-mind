# Реестр субпроцессоров (черновик)

> Обновлять при смене провайдеров. Дата последней ревизии: 2026-05-22.

| Субпроцессор | Назначение | Данные | Регион (по умолчанию) |
|--------------|------------|--------|------------------------|
| **Timeweb Cloud** (S3) | Хранение PDF, превью, exports | Файлы документов | РФ |
| **GigaChat** (Сбер) | LLM: аудит, чат | Текстовые фрагменты документов | РФ (при `AI_PROVIDER=gigachat`) |
| **Yandex Cloud** (YandexGPT) | LLM: аудит, чат | Текстовые фрагменты | РФ (при `AI_PROVIDER=yandex`) |
| **Хостинг Postgres/Redis** | БД и очереди | Метаданные, учётные записи | По договору (Timeweb / иное) |

## Локальная разработка

| Компонент | Назначение |
|-----------|------------|
| Docker: Postgres, Redis, MinIO | Только dev-окружение, без прод-данных |

## Исключения

- Собственный парсер PDF **не используется** — см. [PDF_LICENSES.md](../PDF_LICENSES.md).

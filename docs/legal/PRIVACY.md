## 2. Какие данные обрабатываем

| Категория | Примеры | Цель |
|-----------|---------|------|
| Учётная запись | email, имя, хэш пароля | Аутентификация, tenant |
| Документы | PDF и производные (превью, текст для ИИ) | Сервис просмотра и проверки |
| Технические | IP, `request_id`, логи API | Безопасность, отладка |
| ИИ-запросы | Фрагменты текста документа (без избыточного PII в логах) | Аудит рисков, чат |

## 3. Хранение

- Метаданные — PostgreSQL (EU/РФ — по выбору развёртывания).
- Файлы — S3-совместимое хранилище (Timeweb Cloud или иное по договору).
- Очереди и кэш — Redis.

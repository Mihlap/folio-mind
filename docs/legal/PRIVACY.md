# Политика конфиденциальности Folio Mind

> **Черновик.** Требует юридической экспертизы и заполнения реквизитов оператора.

## 1. Общие положения

Настоящая политика описывает обработку персональных данных при использовании платформы **Folio Mind** (далее — Сервис).

**Оператор:** _[наименование, ИНН, адрес]_.

## 2. Какие данные обрабатываются

| Категория      | Примеры                                     | Цель                 |
| -------------- | ------------------------------------------- | -------------------- |
| Учётная запись | email, имя, хеш пароля                      | Регистрация и доступ |
| Документы      | PDF и метаданные, загруженные пользователем | Функции Сервиса      |
| Технические    | IP, user-agent, request_id, логи            | Безопасность, аудит  |
| ИИ-запросы     | Фрагменты текста документа (по сценарию)    | Аудит, чат, саммари  |

Полный текст документов в логах приложения **не сохраняется** по умолчанию (настраиваемо).

## 3. Правовые основания

- Исполнение договора (оказание услуг Сервиса).
- Согласие пользователя — где требуется (например, маркетинг).
- Законные интересы — безопасность, предотвращение злоупотреблений.

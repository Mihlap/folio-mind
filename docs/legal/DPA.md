# Соглашение об обработке персональных данных (DPA)

> **Черновик** для B2B-развёртывания Folio Mind. Не заменяет подписанный договор.

## 1. Стороны

- **Контролёр:** _[Заказчик — организация пользователей]_.
- **Обработчик:** _[Оператор платформы Folio Mind]_.

## 2. Предмет

Обработчик обрабатывает персональные данные от имени Контролёра в рамках предоставления SaaS/on-prem платформы для работы с PDF и ИИ-функций.

## 3. Категории данных и субъектов

- Сотрудники и контрагенты Контролёра (пользователи Сервиса).
- Содержимое загруженных документов (может включать ПДн третьих лиц).
- Технические журналы (аудит, безопасность).

## 4. Цели обработки

Предоставление функций: хранение, просмотр, версии, фоновая обработка PDF, ИИ-аудит и чат — в объёме, выбранном Контролёром.

## 5. Обязанности Обработчика

- Обрабатывать данные только по документированным инструкциям Контролёра.
- Обеспечить конфиденциальность персонала.
- Уведомлять о инцидентах в срок _[N часов]_.
- Содействовать в DPIA и запросах субъектов — в разумных пределах.
- По окончании договора — удаление или возврат данных по выбору Контролёра.

## 6. Субобработчики

Список: [SUBPROCESSORS.md](./SUBPROCESSORS.md). Изменения — с уведомлением за _[30]_ дней.

При включении GigaChat / YandexGPT:

- Текст документа передаётся провайдеру только для выполнения запроса пользователя.
- Запрет использования данных для обучения моделей — по договору с провайдером.

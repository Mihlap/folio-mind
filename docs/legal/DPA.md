# Соглашение об обработке данных (DPA) — черновик

> **Статус:** шаблон для B2B-клиентов (фаза 0). Юридическое согласование обязательно.

## 1. Стороны

- **Контролёр:** заказчик (клиент Folio Mind).
- **Обработчик:** [оператор Folio Mind].

## 2. Предмет

Обработка персональных данных и содержимого документов **только** для предоставления сервиса Folio Mind по договору и документации API.

## 3. Категории данных и субъектов

По приложению к договору: сотрудники заказчика, контрагенты (если указаны в документах), метаданные загрузок.

## 4. Обязанности обработчика

- Обработка по documented instructions заказчика.
- Конфиденциальность, меры безопасности (шифрование in-transit, ACL, аудит).
- Уведомление об инцидентах в срок по договору.
- Субпроцессоры — только из [SUBPROCESSORS.md](./SUBPROCESSORS.md) с уведомлением.

## 5. Место обработки

РФ / EU — указывается в коммерческом предложении и инфраструктурном приложении.

## 6. Удаление по окончании

По запросу или по истечении срока — удаление из Postgres и S3 в разумный срок (см. runbook в [DEPLOY.md](../DEPLOY.md)).

### Финальная версия PDF (приоритет фазы 3)

Выбранный сценарий: **DOCX-центричный пайплайн**.

```
PDF + принятые правки
        │
        ├─ есть исходный DOCX? ──► правки в DOCX ──► DOCX → PDF (Gotenberg)
        │
        └─ только PDF ──► PDF → DOCX (pdf2docx) ──► правки ──► DOCX → PDF
```

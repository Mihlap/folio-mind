# ICP — целевая аудитория Folio Mind

## ICP 1 (v1): юридический и договорной контур

**Кто:** юристы, compliance, закупки, ИП и SMB с регулярной работой по договорам.

**Документ:** договор, допсоглашение, оферта — преимущественно **текстовый PDF**.

**Jobs-to-be-done:**

- Быстро открыть и прочитать договор в браузере.
- Получить **структурированный аудит рисков** (пропуски, противоречия, спорные формулировки).
- Уточнить в **чате по документу** без копирования в мессенджер.
- Сохранить версии и журнал действий.

**Сценарий v1:**

```
Загрузка PDF → просмотр → ИИ-аудит → отчёт + чат → (позже) правки с подтверждением
```

**Не цель v1:** замена полноценной CMS договоров или ЭДО с квалифицированной подписью.

## ICP 2 (v1.1+): архитектурные бюро

**Кто:** архитекторы, проектировщики, студии презентаций объектов.

**Документ:** **буклет / альбом** — много растров (рендеры, планы, фото), мало текста.

**Боль сегодня:** цикл «скачай PDF → сожми → перекинь в мессенджер»; нет проекта, версий и согласования с заказчиком в одном месте.

**Решение Folio Mind (фаза 2b):**

| Боль | Решение |
|------|---------|
| Crop и позиция картинки на листе | Режим макета, snap, новая версия PDF |
| Нет линеек/направляющих | Линейки мм/см, сетка, направляющие |
| Нет прозрачности/градиентов | Alpha и градиенты; flatten на worker |
| Нет доступа заказчику | Ссылка «только просмотр», комментатор, watermark |
| Ручное сжатие | Пресеты «почта / печать / без сжатия» |

**Сценарий v1.1 (после юр. v1):**

```
Проект «объект X» → медиатека → шаблон бюро → сборка буклета →
пресет сжатия → ссылка заказчику → комментарии и статусы → финал + DPI-чеклист
```

**Ограничения (явно не обещаем):**

- Не AutoCAD / Revit / InDesign / Photoshop в браузере.
- Не CMYK-допечатка в v1–v3.
- Не совместное редактирование «как Google Docs» (только асинхронные комментарии и ссылки).

**ИИ для буклета (лёгкий слой):** подписи к рендерам, черновик титульника, поиск по материалам проекта.

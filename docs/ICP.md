# ICP и сценарий v1

## Целевой сегмент (ICP) v1

**Юридические и договорные команды** (in-house юристы, небольшие юрфирмы, compliance), которые ежедневно работают с **договорами в PDF** и хотят ускорить первичную проверку рисков с помощью ИИ.

Вторичный сегмент (после v1): архитектурные бюро и буклеты — см. [PROJECT_PLAN.md](../PROJECT_PLAN.md) §2.3, фаза 2b.

## Один сценарий v1 (фокус разработки)

1. Пользователь **загружает** договор PDF (10+ МБ, presigned S3).
2. **Просматривает** документ в браузере (PDF.js + превью из worker).
3. Запускает **ИИ-проверку рисков** (очередь, GigaChat или YandexGPT).
4. Получает **отчёт** и уточняет в **чате** по документу.
5. Все действия фиксируются в **журнале аудита**.

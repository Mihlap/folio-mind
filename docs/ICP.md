# ICP — целевая аудитория Folio Mind

## Главный ICP: архитектурные бюро и проектировщики

**Кто:** архитекторы, дизайнеры интерьеров, студии презентаций, проектные бюро.

**Документ:** **буклет / альбом / презентация объекта** — в основном **большие PDF с массой изображений** (рендеры, планы, фото), мало текста. Типичный размер — десятки мегабайт.

**Главная боль:** цикл «собрал PDF → сжал вручную → скачай → перекинь в мессенджер → заказчик не может нормально посмотреть и прокомментировать». Нет единого места для **создания, редактирования, версий и обмена** с заказчиком.

**Jobs-to-be-done:**

- Собрать и **отредактировать** буклет: crop, позиция картинок на листе, линейки, заливки.
- **Сжать при выгрузке** (пресеты «почта / печать / архив») без сторонних утилит.
- **Расшарить заказчику** ссылку «только просмотр», комментарии, watermark «черновик».
- Вести **проект объекта**: версии, медиатека, согласование без пересылки файлов.

**Сценарий (целевой продукт):**

```
Проект «объект X» → медиатека → шаблон бюро → сборка буклета (макет) →
пресет сжатия → ссылка заказчику → комментарии и статусы → финал + DPI-чеклист
```

**Боли с интервью (зафиксированы в плане):**

| Боль                                     | Решение в Folio Mind                                    |
| ---------------------------------------- | ------------------------------------------------------- |
| Обрезка и позиционирование на листе      | Режим макета, snap, сетка                               |
| Линейки / направляющие (как в Photoshop) | Линейки мм/см, направляющие                             |
| Нет прозрачности и градиентов у заливок  | Alpha, градиенты; flatten на worker                     |
| Нет общего доступа с заказчиком          | Ссылка, роли viewer/commenter, без скачивания исходника |
| Постоянное ручное сжатие                 | Пресеты выгрузки на worker (qpdf/Ghostscript)           |

**Фаза в roadmap:** **2b** (после общего viewer и S3). См. [ROADMAP.md](./ROADMAP.md).

**Ограничения:** не AutoCAD/Revit/InDesign; не CMYK-допечатка; не co-editing «как Google Docs».

## Дополнительный ICP: юридический и договорной контур

**Кто:** юристы, compliance, закупки, ИП и SMB с регулярной работой по договорам.

**Документ:** договор, допсоглашение, оферта — преимущественно **текстовый PDF** (обычно меньше по «весу картинок», но важен текст и ИИ-аудит).

**Jobs-to-be-done:**

- Просмотр договора в браузере.
- **ИИ-аудит рисков**, чат по документу, RAG по регламентам.
- Версии и журнал действий.

**Сценарий (первый технический vertical в коде, фаза 1):**

```
Загрузка PDF → просмотр → ИИ-аудит → отчёт + чат
```

Этот сценарий в [PROJECT_PLAN.md](../PROJECT_PLAN.md) описан как **v1 для разработки** — потому что на нём быстрее проверить viewer, S3, очереди и ИИ на **текстовых** PDF. Это **не значит**, что продукт «только для юристов».

## Прочие группы (тот же платформенный контур)

Один и тот же движок (просмотр, версии, S3, сжатие, ссылки, комментарии) подходит и другим ролям:

| Группа                 | Типичный PDF                | Что важно                             |
| ---------------------- | --------------------------- | ------------------------------------- |
| Маркетинг / продажи    | Презентации, каталоги       | Большие файлы, сжатие, ссылка клиенту |
| Строительство / подряд | Альбомы, сметные приложения | Версии, обмен с заказчиком            |
| HR / админ             | Пакеты документов, формы    | Сборка, конвертация (фаза 3)          |
| Юристы                 | Договоры                    | ИИ-аудит, RAG (фаза 2)                |

## Приоритет: продукт vs код

|        | Продукт (для заказчика)                     | Код (roadmap)                               |
| ------ | ------------------------------------------- | ------------------------------------------- |
| **№1** | Архитекторы: буклеты, большие PDF, обмен    | Фаза **2b**                                 |
| **№2** | Общая платформа: viewer, S3, сжатие, ссылки | Фаза **1** (каркас для всех)                |
| **№3** | Юристы: ИИ по договорам                     | Фаза **1–2** (первый vertical в разработке) |
| **№4** | Мобильность на объекте                      | Фаза **4**                                  |

**Итог:** Folio Mind **в первую очередь** закрывает боль архитекторов с **большими PDF** (редактирование, сжатие, обмен). Юристы и остальные группы — **дополнительные сегменты** на той же платформе. В коде сейчас идёт фаза 0–1: общий фундамент; специфика буклетов — фаза 2b.

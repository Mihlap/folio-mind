# Тестовые файлы

## `sample-regulation.txt`

Пример внутреннего регламента для проверки **Сверки с регламентом**:

1. Меню **Регламенты** → загрузить `sample-regulation.txt`
2. Дождаться статуса **готов к проверке**
3. Открыть договор (PDF с текстовым слоем) → **Сверить с регламентом**

В отчёте должны появиться расхождения, если в договоре, например, отсрочка платежа больше 14 дней или пени выше лимитов из регламента.
